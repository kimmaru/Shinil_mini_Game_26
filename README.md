# 몸으로 놀자! 미니게임 파티

웹캠 앞에서 몸으로 하는 미니게임 24종. 컨트롤러·마우스 없이, 카메라가 몸의 관절 위치를
읽어서 진행합니다. 카메라 화면은 이 컴퓨터 화면에만 보이고, 저장하거나 밖으로 보내지 않습니다
(외부 네트워크 요청 0건).

흐름: **시작 → 슬롯머신 룰렛 → 3·2·1 + 동작 설명 → 게임(30–60초) → 결과(별·오늘 최고 기록) → 처음 화면**

카메라에서 **약 1.2m**, 허리 위만 화면에 나와도 놀 수 있어요(23종). 2m 넘게 떨어져 발목까지
보이면 점프 게임(파도 넘기)도 룰렛에 나옵니다.

---

## 윈도우에서 실행하기 (Windows 10/11)

### 처음 한 번만

1. **Node.js 22 LTS** 설치: <https://nodejs.org/ko/download> 에서 Windows 설치 파일(`.msi`)을 받아
   기본값으로 설치.
2. **Google Chrome** 설치(권장). 없으면 윈도우에 기본으로 있는 Edge로 열립니다.
3. 이 저장소를 내려받기 (비공개 저장소라 깃허브 로그인 필요):
   - 깃허브에 로그인한 브라우저에서 **Code → Download ZIP** → 압축 풀기, 또는
   - 명령 창에서 `git clone https://github.com/kimmaru/Shinil_mini_Game_26.git`
4. 윈도우 카메라 권한 확인: **설정 → 개인 정보 및 보안 → 카메라**에서
   "카메라 액세스"와 "데스크톱 앱에서 카메라에 액세스하도록 허용"이 **켬**.

### 실행 — 둘 중 하나

- **더블클릭(추천):** 폴더 안의 `play-windows.bat`를 더블클릭하세요.
  처음 한 번은 필요한 것을 설치하고 빌드하느라 1~2분 걸려요(인터넷 필요).
  ZIP으로 받았다면 "Windows의 PC 보호" 창이 뜰 수 있어요 → **추가 정보 → 실행**.
- **명령 창(PowerShell):** 폴더에서 처음 한 번 `npm install`, 그다음부터는 매번:

```powershell
npm run play
```

Chrome(또는 Edge)이 주소창 없는 전체 화면 창으로 열립니다. `시작`을 누르고 카메라를
**허용**하면 대기 화면이 나옵니다.

### 끝내기

게임 창에서 `Alt + F4`, 그다음 검은 명령 창을 닫으면 끝납니다(명령 창이 게임 서버예요).

## 맥북에서 실행하기 (MacBook Pro 2015, macOS 12, Chrome)

### 처음 한 번만

1. **Node.js 22 LTS** 설치: macOS 설치 파일(`.pkg`). 최신 24 이상은 macOS 12를 지원하지 않을 수 있어요.
2. **Google Chrome** 설치.
3. 이 저장소를 내려받기: 위 윈도우와 같은 방법(ZIP 또는 `git clone`).
4. 처음 실행 때 카메라를 물으면 허용. 이미 거부했다면 **시스템 환경설정 → 보안 및 개인 정보 보호
   → 개인 정보 보호 → 카메라**에서 Google Chrome을 체크.

### 실행 — 둘 중 하나

- **더블클릭:** Finder에서 `play-mac.command`를 더블클릭. ZIP으로 받았다면 맨 처음 한 번은
  **우클릭 → 열기 → 열기**로 실행하세요(인터넷에서 받은 파일이라 macOS가 한 번 확인합니다).
- **터미널:** 이 폴더에서 처음 한 번 `npm install`, 그다음부터는 매번:

```bash
npm run play
```

끝낼 때는 게임 창에서 `Cmd + Q`, 터미널 창은 닫으면 됩니다.

> 처음 빌드할 때 자세 인식 모델(약 15MB)을 Google 서버에서 한 번 내려받습니다. 그 뒤로는 인터넷이 없어도 됩니다.
> 게임이 켜져 있는 동안은 화면이 꺼지지 않게 해 둡니다(몸으로만 놀아서 키보드·마우스 입력이 없기 때문).
> 업데이트를 받은 뒤에도 더블클릭 런처가 필요한 설치와 다시 빌드를 알아서 합니다.

## 첫 실행 체크리스트

- [ ] 카메라에서 약 1.2m에 섰을 때 대기 화면의 "나" 창에 내 몸이 따라 움직이고, 배경에 내 모습이 흐리게 보인다.
- [ ] 주소 뒤에 `?debug=1`을 붙여 열면(`http://127.0.0.1:4300/?debug=1`) 오른쪽 위 디버그 창에서
  - `inference fps`가 **20 이상**, `render fps`가 **50 이상**
  - `tier`에 `GPU · worker`가 보인다 (`CPU`면 느릴 수 있음 — 아래 문제 해결)
- [ ] "한 걸음 뒤로/앞으로" 안내가 뜨면 그 말대로 한 걸음만 옮긴다.

## 조작

- **시작**: 화면의 시작 버튼, `Space`/`Enter`, 또는 카메라 앞에서 **두 손 번쩍(만세)** 0.5초.
  몸 전체가 보이면 제자리 점프로도 시작해요.
- **골라서 하기**: 처음 화면 왼쪽 위 **전체 게임** → 24종 중 하나를 누르면 룰렛 없이 바로 시작.
  결과 화면의 "다시 하기"는 같은 게임을 한 번 더 합니다.
- **룰렛 건너뛰기**: 화면 버튼
- **게임 중 그만하기**: 오른쪽 위 X 버튼 또는 `Esc`
- **설정**(오른쪽 위 톱니): 소리, 배경에 내 모습 보이기, 화면 효과 줄이기, 글자 크게, 진하게 보기, 기록 지우기, 개인정보 안내
- 카메라 없이 해 보기: 준비 화면의 `카메라 없이 쓰기` (키보드: `Space` 점프, `↓` 앉기, `←/→` 이동, `Z`/`X` 손 들기, `C` 박수,
  마우스 = 마우스가 있는 쪽 손)

## 문제 해결

| 증상 | 해결 |
|---|---|
| "다른 앱이 카메라를 쓰고 있어요" | Teams·Zoom·FaceTime·카메라 앱 등을 끄고 다시 시도 |
| "카메라를 못 쓰게 되어 있어요" | 윈도우: 설정 → 개인 정보 및 보안 → 카메라에서 허용. 맥: 시스템 환경설정 → 보안 및 개인 정보 보호 → 카메라에서 Chrome 허용. 그다음 다시 시도 |
| "카메라는 켜졌는데, 준비에 실패했어요" | `npm run play -- --fresh`로 다시 빌드. 그래도 같으면 주소 뒤에 `?worker=off`를 붙여 열어 보기 |
| 몸 인식이 느리다/끊긴다 | 방을 밝게, 창문을 등지고 서지 않기. 설정에서 "배경에 내 모습 보이기"를 꺼서 비교 |
| 아무 반응이 없다 | 머리와 어깨가 화면 안에 들어오게 서기(노트북 화면을 너무 뒤로 젖히지 않기) |
| `play-windows.bat`가 "Node.js is not installed" | Node.js 22 LTS를 설치한 뒤 다시 더블클릭 (설치 직후라면 창을 새로 열기) |
| 화면이 예전 그대로다 | `npm run play -- --fresh` (강제 다시 빌드) |
| 포트 4300을 쓸 수 없다 | 이미 열려 있는 명령 창/터미널 창을 닫고 다시 실행 |

## 개발

```bash
npm run dev          # 개발 서버 (http://127.0.0.1:5173, ?pose=virtual 로 카메라 없이)
npm run gate         # 타입검사 + 경계·동결·자산 검사 + 전체 테스트
npm run shot -- <게임id>   # 게임 화면을 SVG로 렌더 (shots/)
```

작성 규칙은 `AGENTS.md`, 게임 만드는 법은 `docs/GAME_AUTHORING.md`, 이번 완성판의 기획은
`docs/GAME-DESIGN-PLAN.md`, 현재 상태는 `PROGRESS.md`에 있습니다.
